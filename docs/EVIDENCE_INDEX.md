## Operations and public presentation

- The public Forge viewer has no model credential, spending ledger or executor access. A private broker provides one fixed optional trial with atomic $0.05/UTC-day, $1/UTC-month and unchanged lifetime caps; recorded replay remains available when the worker/provider is unavailable.
- MTA uses bounded storage, low-priority supervised workers, read-only public-summary access, automatic retries for completed-day export and explicit stale-data/forecast-expiry handling. The first completed UTC-day export is not claimed before it actually exists.
- RunPod allocations were terminated after artifact recovery. The new TrustQuery work used three setup allocations and one actual experiment; combined allocation-rate estimate $0.151358 and account balance decrease $0.151470 are not a settled invoice. Earlier serving-study billing remains a separate receipt.
- Seven unselected repositories were made private and archived with private Git bundle backups. The active Graph demo links to its public deployed adapter, not the private upstream repository.
- Portfolio, both one-page CVs, GitHub profile and LinkedIn distinguish current implementation, measured evidence and ongoing research. CI success verifies the checks exercised by each repository; it does not prove that every possible input is bug-free.
