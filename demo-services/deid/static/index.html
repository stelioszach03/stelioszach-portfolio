How this prototype works
spaCy's en_core_web_sm proposes names, organisations and places. Prioritized regular expressions detect structured identifiers. The server then applies the chosen policy. Statistical and rule-based detection can both miss or mislabel information; neither proves an output is safe.
Submitted text is processed in memory without deliberate storage by this demo. This page does not save input to browser storage or send analytics. Hashes use a server salt that changes on restart; they remain pseudonyms, not anonymization. Summary JSON contains labels and offsets, not source text or detected values.
