# READ THIS BEFORE INSTALLING ON THE SERVER — torch must come from the CPU index.
#
#   .venv/bin/pip install --index-url https://download.pytorch.org/whl/cpu torch==2.4.1
#   .venv/bin/pip install -r requirements.txt
#
# A plain `pip install torch==2.4.1` on linux/x86_64 pulls the CUDA build and drags
# in ~2.5-3.5 GB of nvidia-* wheels that are useless without a GPU and will fill a
# small VPS disk. The CPU wheel is a few hundred MB. On this machine (arm64 macOS)
# PyPI already serves a CPU-only wheel, which is why the pin below has no nvidia-*
# lines — do not read that as "the CPU index is optional on Linux".
# ##########################################################################
